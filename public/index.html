LocalCorrect Outlook — 1.0.0-rc.1

Open-source, on-device English and German typo correction. No LLM, telemetry or draft-processing server.

Release candidate. Test with synthetic text first. This candidate supports selected text in new HTML messages in Outlook on the web. It produces corrected plain text: review, Copy, then paste deliberately. It never writes to or sends your draft. Clipboard history and device synchronisation remain outside its control.

Install for an owner-test

  1. Download the Outlook manifest.
  2. Where your account and organisation permit it, open Outlook's custom-add-in installation and add that manifest from file.
  3. Open a new HTML message, select your own newly written prose, open LocalCorrect and press Correct.

Requires a supported Microsoft 365/Exchange Online or Outlook.com mailbox and permission to sideload. Desktop Windows, Mac, mobile, replies, forwards and arbitrary IMAP accounts are not supported by this candidate. Real Outlook installation is not yet verified.

Synthetic-text demo · Support · Release downloads and instructions · Source, privacy and self-hosting

Correction runs in your browser. This public site serves static code and dictionaries; GitHub and the required Office.js CDN receive ordinary asset requests, not application-submitted draft contents. You can self-host the reviewed assets instead. This does not make Outlook itself offline or control other extensions.
